# Projeto de Landing Page para App fitness

Página com fundo branco e fonte Roboto como principal.
Objetivo: Criar uma landing clean, branca e sofisticada para um app fitness com intuito de divulgação.

## SECTION 01 - HEADER

### Logo no canto superior esquerdo

- A logo é um F em um circulo (feito com css)
- O fundo do círculo é VERDE ESCURO

### Botão de download no canto superior direito

- fundo verde, cor branca
- borda arredondada (border-radius: 25px)

## SECTION 02 - HERO

A hero deve ter altura 90vh, dividio em 3 áreas horizontais:

### Esquerda

Apenas a headline, sem ser grande mais, sem destaque (o destaque é o print do app no meio).
"O app perfeito para acompanhar sua vida fitness."

### Centro

Em destaque a imagem do arquivo img/print_1.png que é um printe do app.

### Direita

Um lista de pontos-chave sobre app:
- ❤️ Saúde
- 🏃 Exercício
- 🤝 Amigos

## SECTION 03 - FUNCIONALIDADES

Vão ser usadas as 3 imagens do arquivo img/print_2.png até img/print_4.png, que serão exibidas da seguite forma:

- print / texto
- texto / print
- print / texto

Ou seja, irá alterna entre o Print na esquerda e um texto explicativo na direita, vice-versa.

Descrição breve de cada print para você gerar um texto adequado: 

- img/print_2.png = contagem de calorias
- img/print_3.png = Exercícios especificos (corrida, musculação, corrida e etc...)
- img/print_4.png = compartilhamento com amigos

## SECTION 04 - CTA (Call To Action)

Botão grande de download com um texto abaixo dele destacando:

- "Totalmente gratuito"

## SECTION 05 - FOOTER

Logo no canto inferior esquerdo:

- A logo é um F em um circulo (feito com css)
- O fundo do círculo é VERDE ESCURO

Links no canto inferior direito:

- Sobre
- Contato
- Termos de uso
- Política de privacidade
